@himmel/sternzeit dev inspector

Local dev tool only, not part of the package build. Requires pnpm build to have run first (loads ../dist/index.js and ../dist/approx.js directly), and must be served over http, not opened as a file:// URL (ES module imports are blocked there).

Also fixed: altitude = 45° (for atmosphericRefraction), view-direction y = 0.5 (for viewDistanceWithinAtmosphere).

schematic view

Not to scale: earth/sun/moon sizes and distances are chosen for visibility, not physical proportion. Driven by the same Julian Day / latitude / longitude above. Drag to rotate.
